FIND A RAM AXLE RATIO BY VIN

Use the VIN to start, then verify the physical truck.

An axle ratio is one of the key details that can change a RAM truck's chart-backed towing capacity. RAM Tow retrieves the available window sticker for a supported VIN and matches the detected equipment to the correct model-year towing chart.

Look up a RAM VINMatch my trailer first

1. Run the VIN lookup

Enter or scan the 17-character VIN. RAM Tow checks the available Chrysler window sticker and detects the truck's year, model, engine, drivetrain, cab, bed, rear-wheel configuration, and any listed axle information.

2. Review the detected setup

Compare the displayed configuration with the truck in front of you. A clear axle ratio on the sticker can support an exact chart match.

3. Use refinement choices if needed

When the window sticker does not conclusively identify the axle or GVWR, RAM Tow may show a range and let you select a confirmed value to update the tow and payload result.

4. Confirm before relying on the number

Check door-jamb labels, factory build information, owner materials, or ask the dealer to verify the axle ratio and final towing configuration before purchase or towing.

Do not assume that visually similar trucks have the same ratio or rating. The VIN, installed equipment, and applicable RAM chart decide the final answer.
